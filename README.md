## ARO

The Antibiotic Resistance Ontology describes antibiotic resistance genes and mutations, their products, mechanisms, and associated phenotypes, as well as antibiotics and their molecular targets. It is integrated with the Comprehensive Antibiotic Resistance Database (https://card.mcmaster.ca), a curated resource containing high-quality reference data on the molecular basis of antimicrobial resistance.

## Updates

The ARO is under active curation by the CARD curation team, including new terms, relationships, and corrections. Updates are released every 3-6 months here and at the CARD website. **This repo** (https://github.com/arpcard/aro) **does not accept pull requests, but instead only reflects the latest release at** [card.mcmaster.ca](https://card.mcmaster.ca). Please request additions or modifications to the ARO either here via https://github.com/arpcard/aro/issues or at https://github.com/arpcard/amr_curation. The curation team will work with you to incorporate your suggestions into the next release of the ARO.

## Stable Release Versions

The latest version of the ontology can always be found at the OBO Foundry PURL:

http://purl.obolibrary.org/obo/aro.owl

The ontology file (`aro.owl`) is released in RDF/XML, the canonical OWL serialization required by the OBO Foundry ([principle FP-002](https://obofoundry.org/principles/fp-002-format.html)).
